Convert from degrees to radians:
- a) $30\degree$
- b) $-45\degree$
- c) $60\degree$
- d) $90\degree$
- e) $-180\degree$
- f) $225\degree$
- g) $-270\degree$
- h) $167.5\degree$
- i) $527\degree$
- j) $-1080\degree$

## Solution


```math
\begin{aligned}
360 \degree &= 2*\pi \\
180 \degree &= \pi \\
  1 \degree &= \pi/180
\end{aligned}
```

- a) $30\degree = 30 \pi / 180 = \pi / 6$
- b) $-45\degree = -45 \pi / 180 = -\pi / 4$
- c) $60\degree = 60 \pi / 180 = \pi / 3$
- d) $90\degree = 90 \pi / 180 = \pi / 2$
- e) $-180\degree = -180 \pi / 180 = - \pi$
- f) $225\degree = 225 \pi / 180 = 5/4 \pi$
- g) $-270\degree = -270 \pi / 180 = -3/2 \pi$
- h) $167.5\degree = 167.5 \pi / 180 = 335/360 \pi = 67/72 \pi$
- i) $527\degree = 527 \pi / 180 = 527/180 \pi$
- j) $-1080\degree = -1080 \pi / 180 = -6 \pi$
