## Exercise

Convert from radians to degrees:

- a) $-\pi/6$
- b) $2\pi/3$
- c) $3\pi/2$
- d) $-4\pi/3$
- e) $2\pi$
- f) $\pi/180$
- g) $\pi/18$
- h) $-5\pi$
- i) $10\pi$
- j) $\pi/5$

## Solution

```math
\begin{aligned}
2*\pi \mathrm{rad} &= 360 \degree  \\
\pi \mathrm{rad} &= 180 \degree \\
1 \mathrm{rad} &= 180 / \pi \degree

\end{aligned}
```

- a) $-\pi/6 \mathrm{rad} = -\pi/6 * 180 / \pi \degree = -180\pi/6\pi \degree = -180/6 \degree = -30 \degree$
- b) $2\pi/3 \mathrm{rad} = 2\pi/3 * 180 / \pi \degree = 2*180\pi/3\pi \degree = 360/3 \degree = 120 \degree$
- c) $3\pi/2 \mathrm{rad} = 3\pi/2 * 180 / \pi \degree = 3*180\pi/2\pi \degree \mathrm{rad} = 540/2 \degree = 270 \degree$
- d) $-4\pi/3 \mathrm{rad} = -4\pi/3 * 180 / \pi \degree = -4 * 180\pi/3\pi \degree = -720/3 \degree = -240 \degree$
- e) $2\pi \mathrm{rad} = 2\pi * 180 / \pi \degree = 2*180\pi / \pi \degree = 360 \degree$
- f) $\pi/180 \mathrm{rad} = \pi/180 * 180 / \pi \degree = 180\pi/180\pi \degree = 1\degree$
- g) $\pi/18 \mathrm{rad} = \pi/18 * 180 / \pi \degree = 180\pi/18\pi \degree = 180/18 \degree = 10 \degree$
- h) $-5\pi \mathrm{rad} = -5\pi * 180 / \pi \degree = -5*180\pi/\pi \degree = -900 \degree$
- i) $10\pi \mathrm{rad} = 10\pi * 180 / \pi \degree = 10*180\pi / \pi \degree = 1800 \degree$
- j) $\pi/5 \mathrm{rad} = \pi/5 * 180 / \pi \degree = 180\pi/5\pi \degree = 180/5 \degree = 36 \degree$
