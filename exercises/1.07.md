## Exercise

Compute the following:

```math
(a) \sum_{i=1}^{5} i
```

```math
(b) \sum_{i=1}^{5} 2i
```

```math
(c) \prod_{i=1}^{5} 2i
```

```math
(d) \prod_{i=0}^{4} 7(i+1)
```

```math
(e) \sum_{i=1}^{100} i
```

## Solution

```math
(a) 1+2+3+4+5 = 15
```

```math
(b) 2 * 15 = 30
```

```math
(c) 2^5 * (1*2*3*4*5) = 32 * 120 = 3850
```

```math
(d) 7^5 * (1*2*3*4*5) = 16807 * 120 = 2016840 
```

```math
(e) (1+100) + (2 + 99) + (3 + 98) + \ldots + (49 + 52) + (50 + 51) = 50 * 101 = 5050
```
