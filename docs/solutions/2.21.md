## Exercise

Extending the concept from Exercise 20, consider the case where
the NPC has a limited field of view (FOV).

If the total FOV angle is $\phi$, then the NPC can see to the left or right of
its forward direction by a maximum angle of $\phi/2$. 

1. How can the dot product be used to determine whether
   the point $\textbf{x}$ is visible to the NPC?

2. For each of the points $\textbf{x}$ in Exercise 20 determine whether
   $\textbf{x}$ is visible to the NPC if its FOV is $90\degree$.

3. Suppose that the NPC's viewing distance is also limited to a maximum distance
   of 7 units. Which points are visible to the NPC then? 

## Solution

We can compute a vector from the NPC to the point, $\textbf{p} - \textbf{x}$,
and use the dot product this vector and $\textbf{v}$ to find the angle between
NPC's forward direction and the point like so:

```math
\cos \theta 
= \frac {
   \textbf{v} \cdot (\textbf{p} - \textbf{x})
} {
   \|\textbf{v}\| \|\textbf{p} - \textbf{x}\|
}
```

If $\cos \theta < \cos(\phi / 2)$ then the point is in view.

---

Let's compute $\|\textbf{v}\|$ first, so that we can reuse this for each
calculation:

```math
\begin{aligned}
{\|\textbf{v}\|}
&= 
\\&=
   \|
      \begin{bmatrix}
            5 & -2
      \end{bmatrix}
   \|
\\&= \sqrt{5^2 + (-2)^2}
\\&= \sqrt{25 + 4}
\\&= \sqrt{29}

\end{aligned}
```

Let's also compute $\cos (\phi / 2)$:

```math
\cos (\phi / 2) = \cos (90 \degree / 2) = 0.7071067811865476
```

---

```math
(1)\space \textbf{x} = \begin{bmatrix}0 & 0\end{bmatrix}
```

```math
\begin{aligned}

\textbf{x} - \textbf{p}
&= \begin{bmatrix}0 & 0\end{bmatrix} - \begin{bmatrix}-3 & 4\end{bmatrix}
\\
&= \begin{bmatrix}3 & -4\end{bmatrix}

\end{aligned}
```


```math
\begin{aligned}

\cos \theta
&= = \frac {
   \textbf{v} \cdot (\textbf{p} - \textbf{x})
} {
   \|\textbf{v}\| \|\textbf{p} - \textbf{x}\|
}

\\&= \frac {
   \begin{bmatrix}5 & -2\end{bmatrix}
   \cdot
   \begin{bmatrix}3 & -4\end{bmatrix}
} {
   \sqrt{29}
   \sqrt{3^2 + (-4)^2}
}

\\&= \frac {
   5 * 3 + -2 * -4
} {
   \sqrt{29}
   \sqrt{9 + 16}
}

\\&= \frac {
   15 + 8
} {
   \sqrt{29}
   \sqrt{25}
}

\\&= \frac {
   23
} {
   \sqrt{29}
   * 5
}

\\&= 0.8541985556144386

\end{aligned}
```

```math
0.8541985556144386 \geq 0.7071067811865476 = true 
\\ \implies \text{in view}
```

Points 1 and 5 were initially in view.

If the maximum viewing distance is 7 units, then we need to consider 
$\|\textbf{p} - \textbf{x}\|$ for each point.

If it is greater than 7, then the point is out of view.

```math
(1)\space \|\textbf{p} - \textbf{x}\| = 5
```

```math
5 \lt 7 = true
\\ \implies \text{in view}
```

```math
(5)\space \|\textbf{p} - \textbf{x}\| = \sqrt{65} = 8.06225774829855
```

```math
8.06225774829855 \lt 7 = false
```
