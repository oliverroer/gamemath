## Exercise

A common convention in aerospace is that $+x$ points forward/north, $+y$ points right/east, and $+z$ points down.

- a) Is this a left- or right-handed coordinate space?
- b) How would we convert 3D coordinates from these aerospace conventions into our conventions?
- c) What about converting from our conventions to the aerospace conventions?

## Solution

### a)
right-handed

### b)

|               | north | east | up  |
| ------------- | ----- | ---- | --- |
| **aerospace** | +x    | +y   | -z  |
| swap x/y      | +y    | +x   | -z  |
| flip z        | +z    | +x   | +y  |
| **ours**      | +z    | +x   | +y  |

### c)

same, but in reverse

|               | north | east | up  |
| ------------- | ----- | ---- | --- |
| **ours**      | +z    | +x   | +y  |
| flip z        | -z    | +x   | +y  |
| swap y/z      | +y    | +x   | -z  |
| swap x/y      | +x    | +y   | -z  |
| **aerospace** | +x    | +y   | -z  |
