## Exercise

Prove the equation for the magnitude of the cross product
```math
\|a \times b\| = \|a\| \|b\| \sin \theta
```
> Hint: make use of the geometric interpretation of the dot product and try to show how the left and right sides of the equation are equivalent, rather than trying to derive one side from the other.

## Solution

By applying the pythagorean theorem to the unit circle, you can deduce the following identity:
```math
\begin{aligned}
1^2 &= (\sin\theta)^2 + (\cos\theta)^2
\newline
1 &= (\sin\theta)^2 + (\cos\theta)^2
\newline
1 - (\cos\theta)^2 &= (\sin\theta)^2
\newline
\sqrt {1 - (\cos\theta)^2} &= \sin\theta
\end{aligned}
```
---
We can use this to replace $\sin\theta$ like so:

```math
\begin{aligned}
\|a \times b\| &= \|a\| \|b\| \sin \theta
\newline       &= \|a\| \|b\|\sqrt {1 - (\cos\theta)^2}
\end{aligned}
```

---

Next, we'll use the geometric interpretation of the dot product to arrive at a definition of $\cos\theta$:
```math
\begin{aligned}
a \cdot b &= \|a\| \|b\| \cos\theta
\newline
\frac {a \cdot b} {\|a\| \|b\|} &= \cos\theta
\end{aligned}
```

---

We can use this to replace $\cos\theta$ like so:

```math
\begin{aligned}
\|a \times b\| &= \|a\| \|b\|\sqrt {1 - (\cos\theta)^2}
\newline       &= \|a\| \|b\|\sqrt {1 - (\frac {a \cdot b} {\|a\| \|b\|})^2}
\end{aligned}
```

---
Now, we can start expanding both sides:

```math
\begin{aligned}
\|a \times b\| &= \|a\| \|b\|\sqrt {1 - (\frac {a \cdot b} {\|a\| \|b\|})^2}


\newline
\|a \times b\|
&=
\sqrt {a \cdot a} *
\sqrt {b \cdot b} *
\sqrt {
    1 - 
    (
        \frac {a \cdot b} {
            \sqrt {a \cdot a}
            *
            \sqrt {b \cdot b}
        }
    )^2
}


\newline
\|a \times b\|
&=
\sqrt {
    
    (a \cdot a) *
    (b \cdot b) *
    (
        1 - 
        (
            \frac {a \cdot b} {
                \sqrt {a \cdot a}
                *
                \sqrt {b \cdot b}
            }
        )^2
    )
}

\newline
\|a \times b\|
&=
\sqrt {
    
    (a \cdot a) *
    (b \cdot b) *
    (
        1 - 
        
            \frac {(a \cdot b)^2} {
                ({a \cdot a})
                *
                ({b \cdot b})
            }
        
    )
}



\newline
\|a \times b\|
&=
\sqrt {
    (a \cdot a) * (b \cdot b) -  (a \cdot b)^2
}




\newline
\|a \times b\|
&=
\sqrt {
    (a_x^2 + a_y^2 + a_z^2) * (b_x^2 + b_y^2 + b_z^2) -
    (a_x b_x + a_y b_y + a_z b_z)^2
}



\newline
\|a \times b\|
&=
\sqrt {
    a_x^2(b_x^2 + b_y^2 + b_z^2)
    + 
    a_y^2(b_x^2 + b_y^2 + b_z^2)
    +
    a_z^2(b_x^2 + b_y^2 + b_z^2)
    -
    (
        a_x b_x * (a_x b_x + a_y b_y + a_z b_z)
            +
        a_y b_y * (a_x b_x + a_y b_y + a_z b_z)
            +
        a_z b_z * (a_x b_x + a_y b_y + a_z b_z)
    )
}

\newline
\|a \times b\|
&=
\sqrt {
    a_x^2 b_x^2 + 
    a_x^2 b_y^2 + 
    a_x^2 b_z^2 + 
    a_y^2 b_x^2 +
    a_y^2 b_y^2 +
    a_y^2 b_z^2 +
    a_z^2 b_x^2 +
    a_z^2 b_y^2 +
    a_z^2 b_z^2
    -
    (
        a_x^2 b_x^2 +
        a_x b_x a_y b_y +
        a_x b_x a_z b_z +
        a_y b_ya_x b_x +
        a_y^2 b_y^2 +
        a_y b_y a_z b_z +
        a_z b_z a_x b_x +
        a_z b_z a_y b_y +
        a_z^2 b_z^2
    )
}

\newline
\|a \times b\|
&=
\sqrt {
    a_x^2 b_x^2
    + a_x^2 b_y^2
    + a_x^2 b_z^2
    + a_y^2 b_x^2
    + a_y^2 b_y^2
    + a_y^2 b_z^2
    + a_z^2 b_x^2
    + a_z^2 b_y^2
    + a_z^2 b_z^2
    - a_x^2 b_x^2
    - a_x b_x a_y b_y
    - a_x b_x a_z b_z
    - a_y b_ya_x b_x
    - a_y^2 b_y^2
    - a_y b_y a_z b_z
    - a_z b_z a_x b_x
    - a_z b_z a_y b_y
    - a_z^2 b_z^2
}

\newline
\|a \times b\|
&=
\sqrt {
    a_x^2 b_y^2
    + a_x^2 b_z^2
    + a_y^2 b_x^2
    + a_y^2 b_z^2
    + a_z^2 b_x^2
    + a_z^2 b_y^2
    - a_x b_x a_y b_y
    - a_x b_x a_z b_z
    - a_y b_y a_x b_x
    - a_y b_y a_z b_z
    - a_z b_z a_x b_x
    - a_z b_z a_y b_y
}

\newline
\|a \times b\|
&=
\sqrt {
    a_x^2 b_y^2
    +
    a_x^2 b_z^2
    +
    a_y^2 b_x^2
    +
    a_y^2 b_z^2
    +
    a_z^2 b_x^2
    +
    a_z^2 b_y^2
    - a_x a_y b_x b_y
    - a_x a_y b_x b_y
    - a_x a_z b_x b_z
    - a_x a_z b_x b_z
    - a_y a_z b_y b_z
    - a_y a_z b_y b_z
}

\newline
\|a \times b\|
&=
\sqrt {
    a_x^2 b_y^2
    + a_x^2 b_z^2
    + a_y^2 b_x^2
    + a_y^2 b_z^2
    + a_z^2 b_x^2
    + a_z^2 b_y^2
    - 2 a_x a_y b_x b_y
    - 2 a_x a_z b_x b_z
    - 2 a_y a_z b_y b_z
}


\newline
\|
\begin{bmatrix}
    a_y b_z - a_z b_y \\
    a_z b_x - a_x b_z \\
    a_x b_y - a_y b_x
\end{bmatrix}
\|
&=
\sqrt {
    a_x^2 b_y^2
    + a_x^2 b_z^2
    + a_y^2 b_x^2
    + a_y^2 b_z^2
    + a_z^2 b_x^2
    + a_z^2 b_y^2
    - 2 a_x a_y b_x b_y
    - 2 a_x a_z b_x b_z
    - 2 a_y a_z b_y b_z
}

\newline
\sqrt {
    (a_y b_z - a_z b_y)^2
    +
    (a_z b_x - a_x b_z)^2
    +
    (a_x b_y - a_y b_x)^2
}
&=
\sqrt {
    a_x^2 b_y^2
    + a_x^2 b_z^2
    + a_y^2 b_x^2
    + a_y^2 b_z^2
    + a_z^2 b_x^2
    + a_z^2 b_y^2
    - 2 a_x a_y b_x b_y
    - 2 a_x a_z b_x b_z
    - 2 a_y a_z b_y b_z
}

\newline
\sqrt {
    a_y^2 b_z^2
    + a_z^2 b_y^2
    - 2 a_y a_z b_y b_z  
    + a_z^2 b_x^2
    + a_x^2 b_z^2
    - 2 a_z b_x a_x b_z
    + a_x^2 b_y^2
    + a_y^2 b_x^2
    - 2 a_x b_y a_y b_x
}
&=
\sqrt {
    a_x^2 b_y^2
    + a_x^2 b_z^2
    + a_y^2 b_x^2
    + a_y^2 b_z^2
    + a_z^2 b_x^2
    + a_z^2 b_y^2
    - 2 a_x a_y b_x b_y
    - 2 a_x a_z b_x b_z
    - 2 a_y a_z b_y b_z
}

\newline
\sqrt {
    a_x^2 b_y^2 + a_x^2 b_z^2
    + a_y^2 b_x^2 + a_y^2 b_z^2
    + a_z^2 b_x^2 + a_z^2 b_y^2
    - 2 a_x a_y b_x b_y
    - 2 a_x a_z b_x b_z
    - 2 a_y a_z b_y b_z
}
&=
\sqrt {
    a_x^2 b_y^2 + a_x^2 b_z^2
    + a_y^2 b_x^2 + a_y^2 b_z^2
    + a_z^2 b_x^2 + a_z^2 b_y^2
    - 2 a_x a_y b_x b_y
    - 2 a_x a_z b_x b_z
    - 2 a_y a_z b_y b_z
}

\end{aligned}
```
